# 3D Engine
A lightweight 3D rendering engine designed for viewing and interacting with 3D models. Users can import models created in external software or utilize pre-installed sample objects included within the application.<br>
> [!IMPORTANT]
> The current version `(v0.2.2)` includes only one pre-installed object. Support for importing custom models will be added in future updates.

## How to run:<br>
<b>1.</b> Head to <a href="https://github.com/niemaminiona/3D_Engine/releases">Releases</a> and choose version. Examples:<br><br>
`v0.2.1` -> Stable release<br>
`v0.2.1b` -> Beta release (Possible bugs)<br><br>
<b>2.</b> In assets you should be able to download program in .rar or .zip file<br>
<img width="200" height="126" alt="image" src="https://github.com/user-attachments/assets/40df0551-d914-4223-ad62-40c95de2a10b" /><br>
<b>3.</b> After downloading, run the .exe file and enjoy<br>
> (Only one `.exe` exists. At this point, missing it would require a deliberate artistic effort.)

> [!IMPORTANT]
>- This application is currently developed exclusively for `Windows x64`. Cross-platform support is not planned, as this is a personal project maintained by a single developer.<br>
>- This program may not function correctly if `C++` is not installed on your system. (Yes, it’s written in C++. Shocking.) You can download the required components from the official <a href="https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170" target="_blank">Microsoft website</a>
