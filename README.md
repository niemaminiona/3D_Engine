# 3D Engine
Engine for rendering 3d models, you can create your own models in any program and render it here, or you can use example ones that are pre installed in the software<br>
> [!IMPORTANT]
> Current state of the program `(v0.1)` has only one pre installed object, you will be able to view your own in the future

## How to run:<br>
Head to <a href="https://github.com/niemaminiona/3D_Engine/tags">Releases</a> and choose version. Examples:<br>
`v0.2` -> Stable release<br>
`v0.2b` -> Beta release (Possible bugs)<br>
In assets you should be able to download program in .rar file<br>
<img width="200" height="126" alt="image" src="https://github.com/user-attachments/assets/40df0551-d914-4223-ad62-40c95de2a10b" /><br>
After downloading, run the .exe file and enjoy
> [!IMPORTANT]
>This program is made ONLY for `Windows x64`, i dont plan on developing this software on different systems, it is just a personal project made by one person.
